NavalOS — version installable (téléphone et ordinateur)
=======================================================

Contenu : index.html (l'app), manifest.webmanifest, sw.js (mode hors ligne), 3 icônes.

Mettre en ligne gratuitement avec GitHub Pages (une seule fois, ~10 min)
1. Va sur github.com et connecte-toi (ou crée un compte).
2. « New repository » → nom : navalos → Public → Create repository.
3. « uploading an existing file » → glisse les fichiers de ce dossier (pas le dossier lui-même) → Commit changes.
4. Settings → Pages → Source : « Deploy from a branch » → Branch : main / (root) → Save.
5. Attends 1 à 2 minutes. Ton adresse : https://TON-NOM-GITHUB.github.io/navalos/

Installer sur le téléphone
- Android (Chrome / Samsung Internet) : ouvre l'adresse → menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil ».
- iPhone (Safari) : bouton Partager → « Sur l'écran d'accueil ».
- Ordinateur (Chrome / Edge) : icône d'installation dans la barre d'adresse.

Hors ligne : après la première ouverture, l'app fonctionne sans Internet.
Mises à jour : remplace index.html dans le dépôt GitHub par la nouvelle version (même étape 3).
Au prochain lancement avec Internet, chaque appareil reçoit la nouvelle version automatiquement.

Ta progression reste sur chaque appareil (code de sauvegarde dans l'onglet Sources pour la transférer).
Le tuteur IA fonctionne seulement dans la version claude.ai.
Projet d'étude personnel, non officiel : le cahier OREN 001 et les instructeurs font foi.
